# 🚀 CF-Tracker (Codeforces Automation Bot)

An automated Python tool designed to track Codeforces solved problems and synchronize progress with GitHub contributions to maintain an active daily streak.

## 🛠️ Built With
* **Python** — Core programming language.
* **Git & GitHub** — Version control and contribution tracking.

## ⚙️ How It Works
1. Fetches or logs solved problem data.
2. Automatically stages and commits the progress locally.
3. Pushes updates to the GitHub repository to keep the contribution graph active.
